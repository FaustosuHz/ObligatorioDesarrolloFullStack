Este proyecto es el backend para el proyecto de Desarrollo FullStack

Para precargar datos en la base de datos, utilizar las colecciones ubicadas en: dataParaPrecargarMongo

Para ver la coleccion de Postman publicada: https://documenter.getpostman.com/view/31007739/2sBYHNVhrA

Para ver la coleccion de test en Postman buscar en la carpeta test, donde se encuentra el Enviroment y la coleccion, se deberia poder cambiar entre la variable local y Dev

la dev url es: http://obligatorio-desarrollo-full-stack-peach.vercel.app
